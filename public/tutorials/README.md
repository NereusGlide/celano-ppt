# CELANO 标准图文教程

五张横版四步流程概览，加八张细分操作详解图，通过内置 image_gen 生成。网页中的分步文字是配套操作说明；示意图不代表实际页面截图。

| 文件 | 内容 |
| --- | --- |
| ppt.png | 输入主题、选择页数与画质、确认消耗、工作台查看 |
| image.png | 描述画面、选择画质与比例、确认生成、预览与保存 |
| canvas.png | 选中原图、标记区域、填写要求、检查局部修改结果 |
| reference.png | 参考资料、视觉风格系列、Logo、结合主题生成 |
| works.png | 生成完成、个人中心、继续编辑、下载与删除 |

生成提示词记录在 docs/tutorial-image-prompts.md。入口为网站“技术支持”，支持搜索、放大、下载以及配套文字步骤。
