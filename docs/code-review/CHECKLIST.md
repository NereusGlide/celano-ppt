# 代码审查清单

> 用法：审查时按域逐条过，**只标记命中的项**。每条意见加 §5 的前缀（`[BLOCK]`/`[MAJOR]`/`[MINOR]`/`[NIT]`/`[Q]`）。
> 想直接贴进 PR 评论，复制文末「可粘贴版」。

---

## 通用（每次必过）

- [ ] 改动量 ≤ 400 行；超过 800 行已要求拆分
- [ ] PR 描述包含：背景 / 改动 / 影响面 / 自测证据 / 回滚方案
- [ ] 本地 `npm run lint` + `npm run test:image` 通过；涉及前端构建时 `npm run build` 通过
- [ ] 没有夹带无关改动（格式化、重命名已单独成 PR）
- [ ] 没有把密钥、`.env`、本地数据、`data/` 提交进仓库
- [ ] 没有遗留调试代码（`console.log`、临时开关、注释掉的旧实现）

## S — 安全与权限

- [ ] 新增/修改的 `/api/*` 路由先 `requireUser`，且校验了资源归属（`resource.userId === session.userId`）
- [ ] 返回给前端的用户对象经过 `publicUser()`，不含 `apiConfigs`/`apiKey`/密码哈希/凭证指纹
- [ ] 文件路径拼接用了 `path.basename()` + 目录前缀校验
- [ ] 没有放宽 helmet CSP、限流阈值、请求体上限（如放宽，PR 已写明理由与替代缓解）
- [ ] 新增资金入口已单独加严限流
- [ ] 没有无条件设置 `trust proxy`
- [ ] 用户输入（手机号、文件名、指令、ID）都做了长度/格式/白名单校验

## M — 资金与计费

- [ ] 顺序正确：先 `chargeCredits` 成功 → 再调上游 → 失败 `refundCredits`
- [ ] 所有点数做了 `Math.floor` 整数化，无浮点运算
- [ ] 每次余额变动有且仅有一条 `addUsage` 审计流水，`detail` 可读
- [ ] 点数单价来自 `IMAGE_COST`，没有魔法数字
- [ ] 已覆盖四个场景的测试：余额不足 / 上游超时退款 / 重复提交 / 金额为 0 或负
- [ ] 不存在"读用户 → 计算 → 写回"的非原子读改写

## C — 并发与异步

- [ ] 所有 `fetch` 带 `AbortSignal.timeout()`
- [ ] 生图调用经过 `withImageSlot()` 并发闸门
- [ ] `void (async () => ...)()` 最外层有 `try/catch`，失败会退款 + 落状态，不静默吞异常
- [ ] `setInterval` / 事件监听在 `req.on('close')` 或 `useEffect` cleanup 中释放
- [ ] 进程级 `Map`/缓存有上限或淘汰策略
- [ ] ID 生成用 `crypto.randomUUID()`/`randomBytes`，未用 `Date.now()` 拼接
- [ ] 并发任务的状态写入是幂等的（重复回调不会重复扣费/重复加页）

## T — 类型

- [ ] 未新增 `: any` / `as any`
- [ ] 未新增 `!.` 非空断言
- [ ] 外部输入（`req.body`、`JSON.parse`、上游响应）先 `unknown` 再收窄，未直接断言
- [ ] 领域类型复用 `src/types.ts`，未重复内联定义
- [ ] 状态用联合类型，未堆叠多个 boolean

## F — 前端

- [ ] `useEffect` 依赖完整，副作用有 cleanup
- [ ] 列表 `key` 是稳定 id（可排序/可删除列表未用 index）
- [ ] 弹窗有 `role="dialog"` + `aria-modal` + Esc + 焦点陷阱 + 关闭后焦点归还
- [ ] 交互元素是 `<button>`，无 `div onClick`
- [ ] `<img>` 有 `width`/`height` 或 `aspect-ratio`；大图 `loading="lazy"`
- [ ] 新路由页面 `lazy()` 懒加载，未改回静态 import
- [ ] 破坏性操作有二次确认，失败可重试
- [ ] 表单 label 有 `htmlFor`

## P — 性能

- [ ] 新增依赖已说明体积成本（>100KB gzip 需批准）
- [ ] 大 base64 / 大数组未进入高频渲染 state
- [ ] 画布/长列表有 `memo`/`useMemo` 兜底，render 内无重计算
- [ ] 服务端高频路径无同步大文件读写、无大 Buffer 拼接

## D — 设计一致性（CELANO）

- [ ] 颜色全部走 `src/index.css` 令牌，无硬编码 hex
- [ ] 主行动按钮是黑白反转，未着色
- [ ] 该屏只有一个 E4 反转元素
- [ ] 状态用边框形态（实线/虚线/呼吸）表达，未用语义色填充
- [ ] 间距、圆角、动效曲线走既有阶值
- [ ] 澜青 / 朱砂 / 涨跌色未出现在同一视觉单元

## Q — 测试

- [ ] 新增纯逻辑（计费、尺寸、解析、调度、ID）带了 `node --test` 单测
- [ ] bug 修复带了能复现该 bug 的回归测试
- [ ] 测试未依赖真实上游 API / 真实网络
- [ ] 断言的是行为，不是实现细节

## O — 可观测性与文档

- [ ] 用户可见错误文案是中文、可读、可执行，未暴露堆栈/内部 ID/上游报文
- [ ] 日志未打印 `apiKey`、密码、完整 data URL、手机号明文
- [ ] 注释解释"为什么"，非直觉决策/兼容层写了存在原因与删除条件
- [ ] 魔法常数已集中到 `src/shared/`

## AI — AI 生成代码专项

- [ ] AI 产出已逐行读，未整块接受
- [ ] 已核对"影响面清单"，无误改无关文件
- [ ] 新增兼容层标注了删除条件与时间
- [ ] 无 `catch {}` 吞异常、无重复实现已有工具函数、无"为过类型检查而 `as any`"
- [ ] 单次 AI 大改已拆分为多个可独立回滚的 PR
- [ ] UI 改动已对照 `design/celano-ui-spec.html` 复核
